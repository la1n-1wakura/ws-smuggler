# utility
my utility

 Выбор технологического стека
Чтобы утилита была одновременно красивой, эффективной и удобной в разработке для пентеста, 
лучше всего подходит связка Python 3.11+ и специфических библиотек.

1. Ядро (Низкоуровневая эффективность)socket и ssl (Встроенные модули): 
Критически важно. Мы сознательно отказываемся от библиотек вроде websocket-client 
или websockets. Они не позволят вам намеренно ломать заголовки, изменять длину кадра 
(Payload Length) или отправлять несмаскированные данные. Только "сырые" TCP-сокеты 
дадут полный контроль над каждым битом кадра WebSocket.

2. Интерфейс (Красота и интерактивность)rich: Лучшая библиотека для создания потрясающих CLI.
 Поддерживает таблицы, панели, прогресс-бары, подсветку синтаксиса (удобно для вывода 
Hex-дампов пакетов) и разметку текста.
prompt_toolkit: Вместо стандартного input(). 
Она добавит в вашу мануальную утилиту автодополнение команд, историю ввода, удобный выбор 
опций стрелочками и горячие клавиши.

3. Архитектурный каркасc lick или argparse: Для парсинга аргументов командной строки. 
Позволит запускать утилиту как в интерактиввом режиме, так и в режиме одной команды для 
автоматизации (например: ws-smuggler --target scan.me --auto).
